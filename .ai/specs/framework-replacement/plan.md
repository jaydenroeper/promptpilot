# Plan — Framework Replacement

## Doel

Vervang de zes huidige prompt-frameworks door de zes frameworks uit het artikel (C.O.R.E., C.R.E.A.T.E., R.I.S.E.N., P.A.R.A., D.A.R.E., R.O.A.D.). Alleen data-laag verandert; UI en API blijven intact.

## Aanpak

### Stap 1 — `data/frameworks.ts` herschrijven
Vervang alle 6 Framework-objecten. Elk object bevat:
- `id`: afkorting lowercase (`core`, `create`, etc.)
- `name`: volledige naam met punten (bijv. `C.O.R.E.`)
- `goal`: "Best for" uit het artikel
- `description`: uitleg van de letters + wanneer te gebruiken

### Stap 2 — `data/promptLibrary.ts` herschrijven
Vervang alle 6 PromptTemplate-objecten. Elke template:
- Bouwt de prompt op **in de volgorde van de framework-letters**
- Labels de afzonderlijke secties zodat de structuur zichtbaar is in de Prompt-tab
- Gebruikt dezelfde placeholders: `{{audience}}`, `{{platform}}`, `{{tone}}`, `{{topic}}`
