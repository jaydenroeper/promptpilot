# Guidelines

## Core Workflow
1. Read:
   - `.ai/product.md`
   - `.ai/tech.md`
   - `.ai/structure.md`

2. If a feature is unclear or non-trivial:
   - create or update a spec in `.ai/specs/<feature>/`

3. Spec structure:
   - `requirements.md` (user stories + acceptance criteria)
   - `plan.md` (implementation plan)
   - `tasks.md` (checklist)

4. Then implement ONLY based on `tasks.md`

## Rules
- Do NOT skip specs for non-trivial features
- Keep everything MVP-sized
- Do NOT invent features outside `product.md`
- Keep tasks small and executable
- Always link implementation to requirements

## Task Execution
- tasks use: `[ ]` and `[x]`
- mark tasks complete immediately after finishing
- never delete tasks, only update
